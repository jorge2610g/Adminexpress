# Configuración de cobros por cancelación

El panel de Tarifas permite a un superadministrador activar o desactivar el cobro por zona y definir montos distintos para pasajero y conductor. Las zonas nuevas comienzan con el cobro apagado.

La configuración sigue el entorno de la cuenta autenticada y se guarda para la zona seleccionada. La funcionalidad requiere la migración correspondiente del repositorio Expressdelivery; este PR no aplica la migración ni despliega el panel.
